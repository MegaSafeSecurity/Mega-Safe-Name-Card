MEGA SAFE SECURITY — DIGITAL BUSINESS CARD

Files:
- index.html: complete responsive digital business card.

Features:
- Mobile-friendly black, gold and red corporate design.
- WhatsApp share button.
- Downloadable contact card (.VCF).
- Tap-to-call and email links.
- Copy link and native share buttons.

Publish free using GitHub Pages:
1. Create/open a GitHub repository.
2. Upload index.html to the repository root.
3. Open Settings > Pages.
4. Under Build and deployment, choose Deploy from a branch.
5. Select branch main and folder /(root), then Save.
6. Wait for GitHub Pages to publish, then open the provided website URL.
7. Share that URL to customers through WhatsApp.

Note:
The logo in this template is a stylized text emblem, not the original high-resolution logo artwork. Replace the CSS logo marks with your original logo image for exact brand reproduction if desired.
